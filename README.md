# 10xGrow - Call AI Agent Website

This is a simple static website with three primary pages:
- index.html (Home)
- product.html (Product overview)
- product-demo.html (Demo + demo booking)
- contact.html (Contact form)

Styles are in `styles.css` and JS is in `script.js`.

How to run:
1. Open `index.html` in your browser (no server required).
2. For local development with live reload, serve with any static server (e.g., `npx serve` or `python -m http.server`).

Notes:
- Forms are client-side only (no backend). They simulate submission and show a friendly message.
- Multiple CTAs across the site emphasize the product demo page (`product-demo.html`) to increase demo clicks.
